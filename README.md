# B.Tech CS Question Bank & Student Portal

A comprehensive web application developed for the Web Technology assignment by Chawan Vikash. 

This project is built **entirely using standard HTML attributes** (tables, framesets, forms, and lists). It contains absolutely no CSS.

--How to Run the Project

This project requires no servers, databases, or external frameworks. It runs entirely locally in your web browser.

1. **Download the Files:** Clone this repository or download it as a ZIP and extract it. Ensure all HTML files are located in the same main folder.
2. **Open the Entry File:** Locate the `index.html` file in the root of the folder.
3. **Launch:** Double-click `index.html` to open it in your preferred web browser (Chrome, Firefox, Edge, etc.).
